# Delivery — تطبيق الإدارة (Flutter)

نفس قاعدة بيانات Firebase التي تستعملها تطبيقات الزبون والمحل والموصّل.
كل رفع للكود على GitHub يبني ملف APK تلقائياً ويضعه في صفحة **Releases**.

- الدخول ببريد حساب الإدارة وكلمة سره. الحساب يجب أن يحمل `role: admin` في `users/{uid}`.
- **المراجعة:** الإعلانات التي أُخفيت بعد 3 بلاغات أو أوقفها فلتر الكلمات، مع البلاغات وسببها.
- القرار: «أرجعه» أو «احذف» أو «احظر البائع» (يمنعه من النشر ويحذف إعلاناته).
- **المنشورة:** كل إعلانات السوق الحالية.
- **المحظورون:** مع زر رفع الحظر.
- جاهز لعرض رأي الذكاء الاصطناعي (الحقل `ai` في الإعلان) عند تفعيله على الخادم.
